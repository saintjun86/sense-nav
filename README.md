# SENSE NAV — 차량 센서 기반 GPS 비의존 내비게이션

[공개 시뮬레이터](https://sense-nav.ruddyferret.chatgpt.site/) · [GitHub 저장소](https://github.com/saintjun86/sense-nav)

현재 배포된 웹 시뮬레이터 v2.11.0의 소스입니다. 이전 이름은 Park Trace이며, 홈페이지는 시뮬레이터 한 화면으로 구성합니다. 경사는 별도의 기울기 센서 없이 차량 중량·가속·제동 입력·속도 변화와 힘 모델로 추정합니다.

GPS가 약해지는 지하주차장에서 차량 주행 데이터로 **들어온 경로와 주차 위치를 기록**하는 아이디어를 검증하는 웹 프로토타입입니다. 왼쪽에는 지하 내비게이션, 오른쪽에는 차량 제어와 센서 상태를 표시합니다. 모바일에서는 위아래로 배치합니다.

## 빠른 실행

Node.js **22.13 이상**(권장: 최신 LTS), npm, 최신 Chrome/Edge/Safari가 필요합니다. 처음 설치할 때는 인터넷 연결이 필요하며, 이후 합성 시연에는 외부 API가 필요하지 않습니다.

```sh
git clone https://github.com/saintjun86/sense-nav.git
cd sense-nav
npm run install:ci
npm run dev -- --host 127.0.0.1 --port 5188
```

브라우저에서 http://127.0.0.1:5188 을 여세요. macOS에서는 `Park Trace 실행.command`를 사용할 수 있습니다. 포트가 이미 사용 중이면 다른 포트로 실행합니다. 실행 직후 브라우저가 먼저 열리면 잠시 후 새로고침하세요.

로컬 실행에는 로그인이나 Pleos 계정이 필요하지 않습니다.

## 공개 소스 범위

시뮬레이터, 물리·추정 알고리즘, 실행 스크립트, 의존성 잠금 파일과 기술 문서를 포함합니다. 배포 사이트의 프로젝트 식별자, 로컬 환경 설정, 인증 정보, node_modules 및 빌드 산출물은 포함하지 않습니다. `.openai/hosting.json`은 로컬 실행에 필요한 빈 저장소 설정만 포함하며, 별도 사이트에 배포하려면 자신의 호스팅 환경을 설정해야 합니다.

v2.11.0 배포 빌드는 완료했으며 기능 실행·브라우저 확인은 개발자가 직접 진행하는 방식입니다. 이 저장소를 공개하면서 시뮬레이션이나 자동 테스트를 추가로 실행하지 않았습니다. 기존 테스트·벤치마크에는 과거 환경 기준 항목이 있으므로 최신 정확도 검증 결과로 해석하지 마세요.

## 구현한 기능

- 고정 120 Hz 물리 적분: 구동력, 제동력, 구름저항, 공기저항, 중력 경사, 전후진, 조향비, 축거, 차량 외곽 충돌.
- 20 Hz 합성 센서: 구간 휠 이동량·회전속도·속도·조향·페달 사용량. 이상적 기준은 편향/노이즈 없음, 센서 오차 실험에서 개별 조절. 지하 진입 후 GPS 중단, GPS 연속 수신 비교.
- 센서만 사용하는 추측항법: 마찰 제한을 공유하는 회전 모델 + 회전 센서 융합, 구간 이동량 적분, 정차 시 자이로 영점 보정. 차량 중량·페달 입력으로 예상한 평지 가속도와 속도 변화에서 구한 가속도의 차이로 경사를 추정하며 별도 기울기 측정은 사용하지 않음.
- 지도에는 추정 경로와 시연 예정 경로를 표시. 합성 정답과의 수평 오차/RMSE 및 이벤트 기록은 엔진 내부에 유지하며 별도 결과 페이지는 제공하지 않음.
- 1F 중앙 건물·외곽도로 + B1/B2: 층별 230×115m(26,450㎡)의 가로:세로 2:1 직사각형. v2.2 대비 가로·세로 각각 1/2, 층별 면적 1/4로 줄이고 주차장 내부는 폭 7m, 차선당 3.5m의 왕복 2차선과 우측통행 화살표로 구성. 2.75×5m 주차면을 이중 열로 배치해 층당 508면을 제공하며 코어와 교차로 회전 여유 공간은 주차면에서 제외.
- 서측 하행 전용 WD1/WD2, 동측 상행 전용 EU1/EU2 직선 슬로프. 수평 길이 40m, 폭 6.5m, 경사 8%로 층고 3.2m를 연결. 슬로프 위 이동 거리에 따라 높이가 변하고 출구에서 도착 층으로 전환. 차체 전체와 직선 측벽의 충돌을 처리. 램프 연결부는 일방통행, 내부 주차 통로는 왕복 2차선.
- 자동 시연, 일시정지·초기화·1×/2×/4× 배속. 가속·브레이크·핸들·기어는 현재 상태를 표시하는 읽기 전용 계기이며 직접 조작하지 않는다.
- 모든 시뮬레이션 차량의 실제 속도는 전진·후진·내리막·중립 관성 주행 모두 **30 km/h** 이내로 제한. 외부 로그/스트림은 측정 데이터를 변조하지 않고 원본 속도로 재생.
- 내비게이션 하단은 누적 거리·기록 시간·추정 경사·누적 고도(1F=0m)를 표시. 오차 계산은 엔진 내부에 유지하며 지도 하단에는 표시하지 않음.
- 기본 1인칭 뷰: 차량을 화면 하단 중앙에 고정하고 전면 진행 방향이 위쪽을 향하도록 지도를 회전하며 현재 층을 자동으로 따라감. 전체 지도 뷰로 전환하면 기존 북쪽 기준 지도에서 층별로 둘러볼 수 있음. 확대·축소, 회전 방향을 반영한 나침반과 북쪽 기준 미니맵을 제공.
- P + 2초 정차 감지와 주차 위치 표시.
- 차량 상태 패널 하단에 수평 기준선과 차량 옆모습을 표시. 오른쪽을 향한 앞코가 센서 추정 경사만큼 내려가거나 올라가며 0°에서는 수평선과 평행.
- 차량 프로필·실험 설정, 시작·일시정지·초기화·배속을 한 화면에서 제공. 데이터 연결 페이지와 파일 업로드·스트림 조작·실험 내보내기 UI는 제거.
- 엔진의 센서 입력·데이터 파싱·보고서 생성 라이브러리는 후속 개발용으로 유지.

**실제 차량과 직접 연결되어 있지 않습니다.** 제공 프로필은 특정 판매 차량의 실측값이 아닌 예시 제원입니다. 지도도 가상 주차장입니다. 이 결과물은 브라우저 기반 검증 환경이며 Pleos Android 앱 제출물 자체가 아닙니다. 공모전에서 Android 실행파일을 요구한다면 SDK 앱/브리지 구현이 추가로 필요합니다.

## 자동 시연과 센서 조건 비교

1. 주행 환경·차량 프로필을 선택하고 차량 패널 상단의 `시뮬레이션 시작`을 누른다. `서측 직선 입차`는 1F→B2, `동측 직선 출차`는 B2→1F, `B1 순환 주행`은 평지 비교 실험이다.
2. 가속·제동·조향·기어는 자동 운전자의 상태를 표시한다. 방향키·WASD·터치 직접 운전과 수동 페달·기어 변경 기능은 v2.5에서 제거했다.
3. 일시정지·초기화·배속으로 시연을 조절한다. 탭을 숨기면 시연이 일시정지된다. 자동 주차 시 P 기어와 2초 정차로 위치를 기록한다.
4. 첫 화면은 1F의 1인칭 뷰다. 차량은 하단 중앙에 있고 전면은 위쪽을 향한다. 주행 중에는 지도와 층이 차량을 따라간다. 지도 상단의 `전체 지도`를 누르면 기존 북쪽 기준 지도로 전환한다. 층 버튼을 누르면 그 층의 전체 지도를 표시하며, `1인칭 뷰`나 조준점 버튼으로 차량에 복귀한다. 뷰 전환은 진행 중인 시연·기록에 영향을 주지 않는다.
5. `실험 설정 → 이상적 기준`은 편향·노이즈 없는 기준 조건이다. 같은 차량 모델로 합성 주행 데이터와 추정기의 힘을 계산하므로 매우 작은 오차는 실차 성능의 증거가 아니다. 경사 필터의 지연·수치 근사에서 오차가 생길 수 있다.
6. `센서 오차 실험`은 가정한 센서 편향·노이즈를 적용한다. 같은 차량·경로·시드로 회전 센서 사용 여부 등을 바꾸어 결과를 비교할 수 있다. 오차는 센서 입력을 거친 추정 결과에서 계산하며 화면에서 임의로 덧붙이지 않는다.

v2.5는 기본 센서 값이나 추정 알고리즘을 변경하지 않는다. 실제 실행과 비교 결과 확인은 사용자가 담당한다.

## 실제 데이터 확장

현재 홈페이지에는 데이터 연결 화면과 업로드·WebSocket 조작을 제공하지 않습니다. `lib/simulation/data.ts`의 입력 검증·파싱·내보내기, 엔진의 센서 입력, 브리지 예제는 후속 연동 개발용 라이브러리로 유지합니다. `docs/DATA-CONTRACT.md`의 센서 계약과 `lib/simulation/adapter.ts`는 참고 구현이며 Pleos SDK를 직접 호출하지 않습니다. 실차 연동에는 별도 UI·브리지와 권한·시간 동기화·축 방향 검증이 필요합니다.

## 수동 검증 및 빌드 명령

아래 검증 명령은 사용자가 필요할 때 직접 실행할 수 있습니다. 사이트 반영 시에는 빌드만 수행합니다.

```sh
npm run typecheck
npm test
npm run sample:generate
npm run build
```

`public/data/benchmark.json`은 동일한 시드 42로 재생성되는 합성 실험 요약입니다. `public/data/sample-sensors.csv`는 재생 가능한 합성 로그이고 `vehicle-profile.json`은 제원 예제입니다.

`public/data/benchmark.json`, 번들 `sample-sensors.csv`와 `docs/VERIFICATION.md`의 성능 수치는 v2.0 기록입니다. v2.1의 센서·조향·속도 제한 및 v2.2~v2.11의 공간·슬로프·지상 건물·시연 UI·경사 추정 변경 후 재실행하지 않았으므로 현재 성능으로 인용하지 않습니다. 사용자 요청에 따라 기능 테스트·샘플 재생성은 수행하지 않습니다.

v2.1은 30 km/h 제한, 부드러운 조작, 회전 모델 일치, 구간 센서 입력과 기본 운전/오차 실험 프리셋을 추가했습니다. 당시 사용한 합성 기울기 입력은 v2.11에서 제거했습니다. 기본 운전은 이상적 합성 센서 조건이며, 표시 오차가 작더라도 실차 정확도를 의미하지 않습니다.

## 모델의 한계

저속 주행 개념 검증 모델로 서스펜션·충돌 변형·타이어 슬립 동역학·ABS·회생제동은 구현하지 않았습니다. 별도 기울기 측정을 사용하지 않으며 힘 기반 경사 추정은 질량·구동력·제동력·주행 저항 보정에 크게 의존합니다. 관측이 어려운 구간에서는 이전 경사를 유지하며, 이때 이동하면 고도 오차가 누적될 수 있습니다. 가상 주차장의 실제 층은 명시적 연결 상태로 관리하며, 센서 추정 층은 3.2m 층고를 가정한 상대 추정입니다. 실차의 층 식별을 보장하지 않습니다. 불확실성 원은 경험적 지표이고 통계적 신뢰구간이 아닙니다. 외부 데이터에는 정답 좌표가 없어 위치 오차·충돌·정답 경사를 제공하지 않습니다. 탭을 닫거나 새로고침하면 세션이 사라지며 현재 홈페이지에는 내보내기 기능이 없습니다.

최근 18,000개 샘플을 메모리에 보관합니다(합성 입력 기준 15분). 시뮬레이션은 최대 60분입니다. 전체 실행의 누적 RMSE와 최근 샘플 내보내기 범위는 긴 실험에서 다를 수 있습니다. 시뮬레이터 하단의 실시간 텔레메트리·주행 이벤트 카드는 v2.7에서, 실험 결과·데이터 연결 페이지와 내보내기 UI는 v2.10에서 제거했습니다.
