# 공모전 시연 가이드

## 설명 문구

“목적지에 도착한 뒤, GPS가 닿지 않는 지하주차장에서 길을 잃는 문제를 다룹니다. SENSE NAV는 차량 속도와 조향 데이터를 사용해 진입 경로와 주차 위치를 기록합니다. 이 웹 실험실에서는 물리 모델의 실제 움직임과 센서 기반 추정을 나란히 보여주고, 데이터 오차가 결과에 미치는 영향을 검증할 수 있습니다.”

## 시연 흐름

1. 첫 접속의 1F 1인칭 뷰에서 차량이 하단 중앙, 전면 방향이 위쪽으로 표시됨을 소개한다. `전체 지도`로 전환한 뒤 B1·B2 지도를 선택한다. 230×115m의 가로가 긴 2:1 형태, 촘촘한 주차 열, 왕복 2차선, 서측 하행·동측 상행 직선 슬로프를 보여준다.
1층 지도에서는 중앙 사각형 건물, 외곽도로, 슬로프 남쪽의 닫힌 테두리와 도로 단절을 보여준다.

2. `1인칭 뷰`로 돌아와 차량 패널 상단의 시작 버튼으로 자동 시연을 시작하고 가속·제동·조향·기어의 상태 표시를 보여준다. 최고 속도는 30 km/h이며 일시정지와 배속으로 진행을 조절한다.
3. 차량이 서측 입구에 진입하면 이동 거리와 높이 변화를 보여준다. 길이 40m의 직선 슬로프에서 3.2m·한 층 이동한다. 도착 층의 연결 통로를 돌아 다시 진입하면 다음 층으로 내려간다.
4. `서측 직선 입차` 자동 시연에서 GPS 중단, 추정 경로, 추정 경사와 1F=0m 기준 누적 고도를 보여준다. 차량 상태 패널 맨 아래의 옆모습이 수평선에 대해 추정 경사만큼 기울어지는 모습을 보여준다. 앞쪽은 오른쪽이며 내리막에서 앞코가 내려간다. 센서 오차 조건은 실험 설정에서 조절한다. 4× 배속을 지원한다.
5. B2에서 차량이 정렬한 뒤 정차하고 주차 위치를 기록하는 모습을 보여준다.
6. `동측 직선 출차`로 B2→B1→1F 이동과 지상 GPS 복구를 보여준다.

현재 공간의 실행 시간과 기능 동작은 사용자 확인 대상이다. 과거 공간의 주행 거리·99초 시연 시간은 사용하지 않는다. 발표 분량은 사용자 실행 후 정하며 짧은 발표에서는 완료 결과를 미리 준비한다.

## 제출 자료

- 최종 완성 후 사용자가 GitHub에 소스, 잠금된 의존성 목록, 테스트, 샘플, 기술 문서를 올려 제출한다. 개발 중에는 제출용 소스 ZIP을 만들거나 갱신하지 않는다.
- `public/data/benchmark.json`: 과거 v2.0 합성 조건별 재현 실험 기록(현재 버전 성능 아님).
- `public/data/sample-sensors.csv`: 과거 v2.0 입력 형식 예제(현재 지도와 좌표가 다름).
- 발표 영상: 자동 시연과 오차 비교 실험을 실제 브라우저 화면으로 녹화.
- 실행 안내: README의 Node 설치·실행 절차.

현재 웹 호스팅은 개인 비공개 사이트로 시작한다. 심사위원에게 사이트 URL을 전달하기 전 접근 권한과 공모전 제출 방식에 맞는 공개 범위를 정해야 한다. 홈페이지에는 소스 다운로드를 게시하지 않는다.

## 표현의 경계

“실차 센서 연결 완료”, “정확한 층 자동 식별”, “전국 지하 지도 복원”, “검증된 최단 출차 경로”, “센티미터급 위치 정확도”로 설명하지 않는다. 현재 구현은 지하 경로 추정 아이디어를 시험하는 재현 가능한 물리 기반 프로토타입이다. 실차 데이터 연결은 규격과 브리지 입력까지 준비되어 있다. Android 앱·Pleos 권한·실차 데이터 수집은 후속 개발 범위다.
