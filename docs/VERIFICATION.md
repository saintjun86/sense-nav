# v2 검증 기록

이 문서는 v2.0의 과거 기록이다. v2.1 주행 모델과 v2.2 회전 램프 및 v2.3 직선 슬로프·230×115m 공간 및 v2.4 지상 건물·v2.5 자동 시연 UI·v2.6 지하 2층 구성에는 재실행하지 않았다. 현재 버전의 기능 검증은 사용자 담당이며 아래 수치를 현재 성능으로 인용하지 않는다.

검증일: 2026-11-07. Node.js 25.9.0, Codex 내장 Chromium. 최소 Node 버전 22.13.

## 자동 검사

- 물리·항법·데이터·브리지·키보드 테스트 **29개 통과**.
- 3개 차량 프로필 × B3 진입/B1 평지/B3 출차 9개 시나리오 모두 완료, 충돌 0회.
- 각 층 105,600㎡ = 기존 10,560㎡ × 10, 지하 3개 층 확인.
- R1/R2/R3를 전진으로 내려가고 후진으로 올라오며 층·높이가 연속 변하는지 확인.
- 잘못된 층/입구에서 이동하지 않음, 램프 옆벽 관통 방지, 층별 장애물 분리.
- 경사 방향별 중력, 제동·정지·후진 조향·P 잠금·차체 외곽 충돌.
- 지하·슬로프 GPS 중단과 1F 출차 후 GPS 복구.
- 방향키 동시 가속/조향, 한 키만 해제 시 나머지 유지, 브레이크 우선, 좌우 동시 중립, WASD 별칭.
- 동일 시드 재현, 조향 편향 증가에 따른 오차 증가, 연속 GPS 비교.
- 합성 CSV 재생에서 주차 재구성 및 외부 데이터의 정답 지표 없음 확인.
- 데이터 범위/시간 역전/중복/누락/차량 제원 검증 및 브리지 단위 변환.

| 1F→B3 기본 | 394.45 | 27.83 | 0 |
| GPS 항상 수신 | 394.45 | 0.03 | 0 |

기본 실제 이동거리 1,634.52m, 종료 높이 -9.6m. 추정 높이 약 -9.72m. 더 긴 경로의 누적 센서 편향 때문에 v1의 짧은 경로와 오차 수치를 직접 비교할 수 없다. 설정과 전체 조건은 public/data/benchmark.json에 포함한다.

## 브라우저 확인

- 방향키 ↑를 4초 눌러 가속, R1 통과 후 B1/-3.2m 도착.
- ↓ 제동으로 0km/h 정차, ↑+→ 동시 입력으로 평면 위치와 방향 변화.
- 시작·일시정지·직접 운전 1× 고정, 입력 해제 상태 확인.
- 4× 자동 시연이 B1·B2·B3를 통과해 06:34에 P 주차로 완료. 실제 높이 -9.6m, 결과 RMSE 27.83m, 충돌 0회가 코어 실행과 일치.
- 브라우저 실행 오류 로그 없음.
- 390px 모바일 폭에서 세로 배치와 터치 가속/제동, 슬로프 진행률 표시 확인.
- TypeScript 타입 검사 및 ESLint 검사 통과.

## 해석 제한

이 결과는 합성 차량 모델과 웹 동작의 검증이다. 실제 차량이나 Pleos 에뮬레이터를 통한 검증, 독립 측량 정답 기반 실차 오차, 모든 브라우저·장치의 호환성 검증은 아니다. 실험의 실제 위치/층과 센서 추정 위치/층은 별도로 표시한다.

## 2026-11-12 색상 변경 확인

현대자동차 공식 CI의 Hyundai Blue #002C5F, Active Blue #00AAD2, Sky Blue #AACAE6를 적용했다. 브라우저에서 브랜드 아이콘과 활성 탭이 RGB(0,44,95)로 표시됨을 확인했다. 기본 버튼은 Hyundai Blue이며 마우스를 올리면 앱 전용 파생색 #001F44를 사용한다. 시뮬레이터·설정창·실험 결과·데이터 연결 화면, Canvas 지도와 SVG 그래프를 직접 확인했다. TypeScript 검사를 통과했다. 이번 변경은 색상과 색상 설명에 한정하며 물리·항법 계산은 수정하지 않았다.
