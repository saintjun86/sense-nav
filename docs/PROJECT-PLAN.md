# 개발 계획 및 범위

## 문제와 목표

지하주차장·터널에서 GPS가 약해지면 내 위치와 진입 방향을 잃기 쉽다. 정밀 주차장 지도 확보보다, 마지막 GPS 기준점 이후 차량 이동을 상대 경로로 기록하고 주차 위치와 돌아갈 방향을 이해하도록 돕는다.

사용자와의 공모전 논의에서 도출한 세 가지 가설:
1. 차량 속도와 조향 변화로 GPS 중단 이후의 상대 이동 경로를 추정할 수 있다.
2. 평지에서 예상되는 가속·제동 반응과 실제 속도 변화의 차이를 경사 추정에 사용할 수 있다.
3. 주차 시점과 진입 경로를 저장하면 도면이 없는 주차장에서도 방향 회복에 도움이 된다.

과거 채팅의 원문이나 개인 정보는 제출 패키지에 포함하지 않는다. 정확한 공모전 명칭·접수 일정·제출 양식은 이 개발 범위에서 확인되지 않았으므로 공식 요강과 별도로 대조한다.

## 구현 단계와 완료 조건

| 단계 | 결과 | 상태 |
|---|---|---|
| 요구사항 정리 | 웹 분할 화면, 물리 검증, 센서 경로, 데이터 입력 | 구현 반영 |
| 물리 코어 | 종방향 힘, 저속 자전거 모델, 충돌, 경사 | 자동 테스트 통과 |
| 항법 코어 | 정답과 분리한 센서 입력, 경사·고도 추정 | 자동 테스트 통과 |
| 웹 시연 | 자동 시연, 배속, 분할 화면, 차량 상태 계기, 그래프·이벤트 | v2.5에서 직접 운전 제거 |
| 공간 확장 v2 | 층별 10배 면적, B1/B2/B3, 양방향 슬로프와 층별 충돌 | 29개 테스트에 포함 |
| 탐색 화면 | 층 선택·전체 지도·차량 추적·미니맵·실제/추정 층 구분 | 구현 |
| 외부 데이터 계약 | CSV/JSON 재생, WebSocket 입력, 제원 검증 | 구현 |
| 재현·제출 | 시드, 벤치마크, 문서; 최종 완성 후 사용자 GitHub 제출 | 개발 중 소스 ZIP 갱신·게시 중단 |

## 아키텍처

```text
가속/제동/조향/기어 ──→ 120 Hz 물리 코어 ──→ 정답 궤적
                              │
                   20 Hz 합성 센서 + 편향/잡음
                              │
CSV/JSON 또는 WebSocket ──→ 검증된 센서 프레임
                              │
                   정답을 읽지 않는 추측항법
                              │
                   경로·경사·주차 추정·기록
                              │
            분할 화면 / 그래프 / CSV·JSON 내보내기
```

자동 시연 운전자는 가상 환경의 정답 위치와 미리 지정한 경로를 사용해 페달과 조향을 정한다. 이것은 차량을 움직이는 테스트 장치다. 항법 추정기는 이 정답 위치·램프 도형·층 ID를 읽지 않는다. 측위 성능은 이 추정기 출력과 별도로 보관한 정답을 비교한다. 외부 로그에는 정답이 없으므로 측위 성능 수치를 만들지 않는다.

## 후속 실차·Pleos 단계

1. 사용 가능한 플랫폼/차종/권한을 조사하여 속도·핸들각·기어·페달의 실제 가용성 표 작성.
2. Android/Pleos 또는 차량 API 브리지를 구현하고 타임스탬프/부호/단위를 검증.
3. 실측 차량 질량·조향비·유효 타이어 반경·구동/제동 맵 보정.
4. 기울기 측정 없이 질량·페달·속도 변화 기반 경사 추정을 보정하고, 방향에는 사용 가능한 yaw-rate·휠속도·조향을 융합한다. 층고·시설 기준점으로 누적 고도 보정 가능성을 검토한다.
5. 측량한 주차장 경로와 여러 층 램프에서 독립 정답을 수집해 실차 오차 평가.
6. 일방통행·층 연결·안전 제한을 포함하는 출구 경로 그래프와 대조.
7. 공모전이 요구하는 Android 패키지, SDK 시연 영상, 양식·분량을 공식 요강에 맞춰 준비.

## 성공 기준

현 버전은 합성 실험이 재현되고, 센서 오차를 조작하면 위치 오차가 변하며, 입력 파일/스트림이 동일한 추정기를 통과하는 것을 보여준다. 실제 정확도·법적 안전성·전국 주차장 대응을 검증한 제품으로 표현하지 않는다.


## v2.1 주행 오차 개선

30 km/h 물리 속도 제한, 부드러운 수동 조작, 마찰 제한 회전 모델 공유, 구간 휠 이동량·자이로·기울기 입력, 정차 자이로 보정, 기본 운전/센서 오차 실험 분리, 수평·방향·높이·층 오차 표시를 구현한다. 기존 v2.0 테스트 결과는 이 변경의 검증 결과가 아니다. 사용자 지정 흐름에 따라 배포용 빌드만 진행하며 실행·기능 검증과 피드백은 사용자가 담당한다.

## v2.2 주차장 개편

- 가로:세로 2:1(460×230m), 지하 3개 층을 유지한다.
- 서측 하행·동측 상행을 분리한 일방통행 나선형 램프. 한 바퀴에 3.2m·한 층 이동.
- 7m 왕복 2차선, 이중 주차 열, 코어와 회전 여유 공간을 제외한 층당 3,176면.
- 누적 회전각 기반 층 전환, 원형 벽 차체 충돌, 근처 장애물 검색과 새 자동 시연 경로를 구현한다.
- 지도·미니맵·회전 진행 안내·문서를 같은 공간 정의에 맞춘다.

위 표의 자동 테스트 통과와 v2 검증은 과거 기록이다. v2.1/v2.2는 사용자 지시에 따라 게시용 빌드만 수행하고 기능 테스트·브라우저 확인은 사용자가 담당한다.

## v2.3 공간 축소·직선 슬로프

- 가로·세로 각각 절반인 230×115m, 면적은 26,450㎡/층으로 변경한다.
- 차량 치수·2.75×5m 주차면·7m 왕복 2차선은 유지하고 5개 이중 주차 열, 층당 508면을 배치한다.
- 서측 하행·동측 상행을 각각 길이 40m·폭 6.5m·경사 8%의 직선 슬로프로 변경한다.
- 누적 회전각 대신 직선 이동 거리로 높이를 계산하고, 측벽·입출구·시연 경로·지도·안내를 갱신한다.
- 게시용 빌드만 수행하고 실행·기능 확인은 사용자가 담당한다.

## v2.4 1층 지상 배치

- 1층 내부 격자 도로를 제거하고 사각형 건물과 외곽 왕복 2차선 도로를 표시한다.
- 슬로프 남쪽 막음면과 그쪽의 도로 단절을 지도·미니맵에 반영한다.
- 건물과 지상 막음면에는 충돌을 적용하되 슬로프에서 층간 이동 중인 차량을 지상 막음면으로 막지 않는다.
- B1~B3와 기존 입출차 시연 경로는 유지하며 사용자 요청대로 빌드·게시만 진행한다.

## v2.5 직접 운전 제거와 기준 조건 명시

- 키보드·터치 직접 운전 모드 및 수동 페달·기어 변경을 제거한다.
- 차량 패널은 읽기 전용 상태 계기와 시연 시작·일시정지·초기화·배속을 제공한다.
- 기본 프리셋을 `이상적 기준`으로 명명하고 오차가 작게 나오는 조건을 설명한다.
- 센서 편향·노이즈 기본값과 추정 알고리즘은 유지한다. 센서 오차 실험을 주 시연으로 사용하는 것은 후속 제안이다.
- 제거한 키보드 기능에만 해당하는 옛 검사 코드를 정리하며 테스트는 실행하지 않는다.

## v2.6 B2까지만 운영하고 조작·고도 표시 정리

- 첫 접속 지도는 1F로 고정하고 층 구성은 1F/B1/B2로 축소한다.
- WD3/EU3와 B3 주행 경로를 제거하고 B2 주차·출차로 변경한다.
- 시작·일시정지·초기화·배속 및 진행률을 차량 패널 상단에 배치한다.
- 내비게이션 하단의 오차 지표를 제거하고 추정 경사 옆에 1F=0m 기준 누적 추정 고도를 표시한다.
- 오차 계산과 실험 결과·CSV/JSON 기록은 유지한다. 게시용 빌드만 실행하고 기능 확인은 사용자 담당이다.

## v2.7 두 가지 지도 뷰와 화면 간소화

- 시뮬레이터 하단 실시간 텔레메트리·주행 이벤트 그룹을 삭제한다. 실험 결과의 기록·그래프 및 내보내기는 유지한다.
- 기본 1인칭 뷰에서 차량은 하단 중앙에 고정하고 전면 방향은 화면 위쪽을 향한다. 차량 이동·회전에 맞춰 주변 지도를 이동·회전하고 현재 층을 자동 추적한다.
- 전체 지도 뷰는 기존 북쪽 고정·층별 보기로 제공한다. 층 버튼 선택은 전체 지도, 조준점은 1인칭 복귀로 연결한다. 뷰 변경 시 기본 확대 배율을 복원한다.
- 회전된 화면 영역을 미니맵에 표시하고 나침반과 지도 라벨 방향도 카메라에 맞춰 처리한다.
- 센서 기본값·실제 물리·추정 경로 계산은 유지하고, 게시용 빌드만 진행한다. 실제 화면·기능 확인은 사용자 담당이다.

## v2.8 경로 옵션 삭제와 추정 경사 시각화

- 내비게이션의 정답 경로 비교·진입 경로 역방향 보기와 관련 상태·그리기 옵션·범례를 제거한다.
- 차량 상태 그룹 맨 아래에 고정 수평선과 오른쪽 전면의 차량 옆모습을 배치한다.
- 추정 경사 라디안을 각도로 변환해 SVG 차량을 1:1 회전한다. 0°는 수평, 음수는 앞코 하강, 양수는 앞코 상승이다.
- 센서·물리·오차 계산은 유지하고 게시용 빌드만 수행한다. 실제 실행과 화면 확인은 사용자 담당이다.

## v2.9 자동 주차 자세 보정

- 마지막 목표점까지의 거리·속도만 확인하던 입차 종료 조건을 위치와 방향을 함께 확인하도록 변경한다.
- 마지막 18m에 저속 주차 제어를 적용하고 경로 접선·곡률, 주차 중심선 및 목표 방향을 추종한다.
- 정렬되지 않은 채 도착하면 짧게 후진해 재진입한다. 후진·전진 전환 시 먼저 감속하며 물리 엔진을 통해서만 이동한다.
- 중심선 오차 8cm·방향 차이 1° 등 완료 조건을 만족해야 P로 전환한다. 센서 모델과 2초 정차 기록은 유지한다.
- 게시용 빌드만 진행하고 실제 정렬 상태와 동작 확인은 사용자 담당이다.

## v2.11 주행 데이터 기반 경사 추정

- 기울기 측정값의 생성·스키마·파싱·브리지·설정과 추정기의 우선 적용 분기를 제거한다.
- 페달의 구간 평균과 속도 차분을 같은 시간축에서 비교해 평지 예상 가속도와의 힘 잔차로 경사를 계산한다.
- 정차·속도 제한·기어 전환·급제동·급조작·큰 회전·이상 가속도 구간에서는 관측을 보류한다.
- 추정 경사로 차량 그림·고도·층을 계산하고 실제 경사를 정답 입력으로 사용하지 않는다.
- 합성 모델의 차량 제원과 힘 계수는 예시이며 실차 데이터 보정과 검증은 후속 작업이다. 게시용 빌드만 수행한다.
