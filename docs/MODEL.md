# 물리 및 항법 모델

## 좌표와 시간

위치는 m, 속도는 m/s, 내부 각도는 rad이다. 지도 좌표는 x 오른쪽·y 아래, heading=0은 오른쪽, 양수는 시계방향이다. 높이 z는 위쪽 양수. 기본 입차 시작점은 (70, 12.25, 0), heading=π. 전진 속도는 양수, 후진은 음수다. 물리 적분 dt=1/120초, 합성 센서 dt=0.05초. 렌더링 속도·배속과 적분 간격을 분리한다. 화면 프레임이 오래 지연되면 벽시계 시간을 따라잡지 않고 시뮬레이션이 느려진다.

## 종방향

```text
F_drive = gear_sign × min(throttle × maxDriveForce, μmg)
F_brake = min(brake × maxBrakeForce, μmg)
F_roll  = Crr × mg
F_drag  = 0.5 × airDensity × CdA × v|v|
F_grade = -mg sin(grade)
a = (F_drive + F_grade - F_drag - sign(v)(F_brake + F_roll)) / m
```

정지점에서는 브레이크·구름저항이 정지 마찰처럼 움직임을 억제한다. 제동으로 속도가 0을 지날 때 힘의 조건을 검사하여 불필요한 역전 진동을 막는다. P는 정지 잠금, N은 경사에서 구를 수 있다. 속도는 전진·후진 모두 절댓값 30 km/h(8.333… m/s)로 제한한다. 내리막·중립에서도 같은 상한을 적용하는 시뮬레이션 속도 제한이며, 실제 차량의 토크 제어기를 재현한 것은 아니다. API에서 가능한 물리 입력 범위를 검증한다.

## 횡방향과 충돌

```text
wheelAngle = steeringWheelAngle / steeringRatio
headingRate = v / wheelbase × tan(wheelAngle)
|headingRate| <= μg / max(|v|, 0.2)
```

중간 방향과 평균 속도로 위치를 갱신한다. 물리 코어와 추정기의 `turnRate`는 같은 마찰 제한을 사용하되, 추정기는 센서 속도·조향만 입력받는다. v2.5부터 차량 입력은 자동 시연 운전자가 생성하며 수동 운전 입력은 제공하지 않는다. 차체 중심을 상태 기준점으로 사용하는 단순 자전거 근사이며 정확한 무게중심 동역학/슬립각 모델은 아니다. 차체 길이·폭을 가진 회전 사각형과 벽·주차 차량 사각형을 분리축 정리로 검사한다. 접촉 시 이전 자세로 되돌리고 속도를 0으로 하므로 충돌 변형이나 반발계수 계산은 없다. 횡/종 타이어 힘의 완전한 마찰원 결합은 구현하지 않는다.

## 지하 2층과 직선 슬로프

지하 각 층은 가로 230m·세로 115m, 면적 26,450㎡의 2:1 직사각형이다. v2.2 대비 가로와 세로는 각각 절반, 면적은 1/4이다. 내부 도로는 폭 7m(3.5m씩 왕복 2차선), 주차면은 2.75×5m를 유지한다. 이중 주차 열과 0.5m 중앙 분리대를 5열 배치하며 두 개 구역을 합쳐 560개 후보 중 교차로 회전 여유 공간 40면과 코어 12면을 제외한 508면을 구성한다. 이는 가상 환경의 설계값이다.

1층은 (35.5,17.5)부터 161×80.5m의 사각형 건물 충돌 영역을 두고 내부 통로를 제거한다. 외곽도로는 x=32/200, y=14/101.5를 따라 배치하고 북쪽에서만 두 슬로프에 연결한다. 슬로프 남쪽 y=75 막음면은 1층 평지에서만 충돌하며 슬로프 위 차량에는 적용하지 않는다. 따라서 지상에서는 막힌 면을 통과할 수 없고 지하 층간 이동은 가능하다. 지도와 미니맵은 같은 층별 도로·건물·막음면 정의를 사용한다.

1F 진입 공간과 B1/B2를 분리하고 물리 상태에 `level`, `rampId`를 저장한다. 2D 평면과 높이 제약을 사용하는 2.5D 모델이며 완전한 3D 강체·서스펜션 모델은 아니다.

| 위치 | 링크 | 이동 | 평면 진입→출구 |
|---|---|---|---|
| 서측 하행 | WD1 / WD2 | 1F→B1 / B1→B2 | (16,35)→(16,75), 남쪽 방향 |
| 동측 상행 | EU2 / EU1 | B2→B1 / B1→1F | (214,75)→(214,35), 북쪽 방향 |

각 슬로프는 수평 길이 40m, 폭 6.5m이며 층고 3.2m를 연결한다. 구배는 8%, 중심선의 경사각은 약 4.57°다. 서측은 하행, 동측은 상행 전용이다. 층마다 슬로프를 나온 후 평지 연결 통로로 이동하며 다음 층으로 가려면 같은 쪽 입구로 다시 진입한다.

진입면을 지정 방향으로 통과할 때 해당 층의 슬로프에 진입한다. `t = 입구부터 중심선에 투영한 거리 / 40`, `z = -(from + (to-from) × t) × 3.2`로 높이를 연속 갱신한다. 출구를 통과하면 도착 층으로 바뀌고, 차량 전방으로 투영한 경사를 중력에 적용한다. 회전각 기반 높이 계산은 제거했다.

차체의 회전 사각형과 직선 측벽을 분리축 정리로 충돌 판정해 측면 이탈을 막는다. 출구를 통한 반대 방향 진입 및 서측 B2·동측 1F에서의 추가 진입은 차단한다. 이미 진입한 슬로프 안에서 후진해 출발 층으로 되돌아가는 것은 허용한다. 충돌 시 위치·높이·층을 이전 상태로 복원한다. 주차 차량은 공간 격자로 가까운 후보를 찾은 후 충돌 판정한다.

자동 시연은 축소된 공간의 차선·슬로프에 맞춘 경로를 사용한다. 통로의 직각 모서리는 원호로 연결하고, 앞을 보는 거리는 속도에 맞춰 조절하며 슬로프와 회전 구간에서 감속하도록 구성한다. 경로 근접도에 높이 차이를 포함해 같은 XY의 다른 층을 혼동하지 않게 한다.

층 연결과 지면 높이는 물리 코어·시각화·자동 운전자만 사용한다. 항법 추정기는 이를 읽지 않는다. 시작 위치와 층은 시나리오의 알려진 기준점으로만 초기화한다. 평지 실험은 B1에서, 출차 실험은 B2에서 시작한다. 자동 GPS는 1F 평지에서만 수신하며 지하층과 슬로프에서 꺼진다.

지도는 선택한 층의 경로를 표시한다. 흰 차량은 합성 정답 위치, Active Blue 점·선은 센서 추정이다. 외부 데이터는 센서 추정 차량만 표시한다. 층 선택은 관찰 시점 변경이며 물리 상태를 바꾸지 않는다.

## 위치 추정

기본 센서 입력은 측정 속도, 핸들 각도, 기어, 페달, 시간, 사용 가능한 GPS 상대 좌표다. 선택 필드로 구간 휠 이동량 `wheelDistanceM`, 평균 회전속도 `yawRateRadps`, 시간 평균 페달 입력 `intervalThrottle`·`intervalBrake`를 받는다. 합성 센서는 각 1/120초 구간의 휠 이동·회전·페달 명령을 모아 0.05초마다 전달한다. 기울기 측정값은 생성하거나 입력받지 않는다. 충돌로 거부된 물리 구간에는 휠 이동이 없고, GPS가 꺼진 구간에는 정답 좌표·높이·층·경사를 전달하지 않는다. 화면의 가속도도 측정 속도의 시간 차분으로 계산한다.

방향은 자이로 회전속도 95%와 마찰 제한을 적용한 조향 예측 5%를 결합한다. 두 값 차이가 0.15 rad/s보다 크면 해당 구간의 자이로를 우선한다. 정차 시 시간상수 2초로 자이로 영점을 학습한다. 자이로가 없거나 사용을 끄면 속도와 이전·현재 조향의 평균으로 추정한다. 위치는 구간 이동량과 원호 적분으로 계산한다. 휠 이동량이 없으면 이전·현재 속도의 사다리꼴 적분으로 대체한다. 이는 단순 상보 융합이며 EKF나 통계적으로 검증된 추정기가 아니다. GPS가 있으면 시간상수 0.7초의 보정으로 상대 좌표와 heading을 맞춘다. 실제 서비스에서는 GNSS 품질·이상치 검사와 기준 좌표 변환이 추가되어야 한다.

센서 생성은 고정 시드 42를 사용한다. 이상적 기준 프리셋은 모든 편향과 노이즈가 0이다. 오차 실험 프리셋은 속도 +0.6%, 조향 +0.5°, 자이로 +0.05°/s, 노이즈 강도 0.35로 시작한다. 이 값들은 실차 분포로 검증된 수치가 아닌 조절 가능한 실험 변수다. 같은 차량 모델로 합성 측정값과 추정기의 힘을 계산하는 기본 조건은 실차보다 유리하다. 임의의 경사 오차를 덧붙이지 않으며 경사 필터의 지연과 수치 근사에서 오차가 생길 수 있다.

## 경사 추정

```text
observedAcceleration = (measuredSpeedNow - measuredSpeedBefore) / Δt
flatAcceleration = (F_drive - sign(meanSpeed) × (F_brake + F_roll) - F_drag) / mass
gravityResidual = (flatAcceleration - observedAcceleration) / g
estimatedGrade = asin(lowPass(gravityResidual))
```

경사는 위 힘 잔차만으로 추정한다. 차량 질량·구동력·제동력·구름저항·공기저항 모델에 같은 구간의 평균 페달 입력과 평균 속도를 넣는다. 평균 페달 필드가 없는 로그는 이전·현재 프레임의 평균으로 근사한다. 별도 가속도 텔레메트리는 경사 계산에 사용하지 않는다. 평지 예상 가속도보다 관측 가속도가 크면 내리막(음수), 작으면 오르막(양수)으로 해석한다. 전후진 속도는 부호를 유지한다.

힘 잔차를 시간상수 0.65초로 저역 통과 필터링한다. 양 끝 속도가 모두 0.7m/s 초과이고 부호가 같을 때 관측한다. 어느 한 끝이라도 최고 속도에서 0.7m/s 이내, 기어 변경 또는 P, 브레이크 45% 이상, 프레임 간 페달 변화 8%p 이상, 추정 횡가속도 2.5m/s² 이상, 관측 가속도 절댓값 5m/s² 이상이면 이전 경사를 유지한다. 힘 잔차가 경사 ±0.35rad 범위를 벗어나도 관측하지 않는다. 속도 제한 여유 폭은 편향이 있는 속도 측정에서도 제한 작동을 경사로 오인하지 않도록 보수적으로 둔다. 임계값과 필터는 실차에서 보정해야 할 프로토타입 설정이다.

`gradeObservable`은 해당 프레임으로 경사를 갱신했는지를 나타낸다. 차량 그림에는 추정 중 또는 관측 대기 상태를 표시한다. 높이는 부호 있는 이동량에 `sin(estimatedGrade)`를 곱해 누적한다. 관측이 중단되어도 이동 중이면 유지한 경사로 적분하므로 고도 오차가 누적될 수 있다. 정차 시에는 이동량이 없어 고도가 변하지 않는다. 실제 층·경사·고도로 추정값을 강제 보정하지 않는다. 시작 기준점과 층고 3.2m를 가정하며 층 경계 절반에서 반올림한 상대 층 번호를 표시한다.

차량 질량과 구동·제동 힘의 정확한 보정 없이 페달 사용량과 속도만으로 경사를 유일하게 분리할 수 없다. 회생제동, 타이어·노면, 적재량, 구동 응답 지연, 변속 등도 속도 변화에 영향을 준다. 합성 센서가 같은 차량 파라미터 모델에서 나오므로 실차보다 유리한 조건이다. 이 실험은 가설의 동작을 보여주며 실차에서 식별 가능하다는 증명은 아니다.

## 지표와 기록

- 수평 오차: `sqrt((x_true-x_est)^2 + (y_true-y_est)^2)`.
- RMSE: 센서 시점의 수평 오차 제곱 평균의 제곱근. 현재 세션 전체 누적.
- 최대 오차: 세션의 최대 수평 오차.
- 방향 오차: 실제/추정 heading의 최단 각도 차이 절댓값(degree).
- 높이 오차: 실제/추정 z 차이 절댓값(m).
- 층 판정 차이: 실제 높이와 추정 높이 모두 같은 층고 반올림 규칙을 적용한 층 번호 차이. 슬로프 중간의 물리 `level` 전환 시점 차이를 제외한다.
- 불확실성 원: 거리와 회전량에 비례하여 커지고 GPS로 작아지는 경험적 시각화. 확률 분포·95% 신뢰구간 아님.
- 주차: 속도 절댓값 0.1m/s 미만 + P 기어 2초 연속.
- 외부 데이터: 정답 좌표, 충돌 수, 정답 경사를 제공하지 않으며 NaN 값을 CSV에서는 빈 칸, JSON에서는 null로 내보냄.

메모리 기록은 최근 18,000개 샘플로 제한한다. 기록된 불확실성과 경로는 새로고침하면 사라진다. 현재 UI에는 결과 내보내기가 없다.

내비게이션의 누적 고도는 1F=0m 기준의 추정 z 값으로 표시한다. 1F/B1/B2를 선택할 수 있으며 최초 지도는 1F이다. 최하층보다 낮게 추정되면 층 라벨을 `B2 아래`로 표시하고 고도 원값은 유지한다. 지도 하단에는 오차를 표시하지 않으며 오차 계산은 코어에 유지한다. v2.10에서 실험 내보내기 UI도 제거했다.

### v2.11 입력 경계

물리 엔진은 도로의 실제 경사를 중력 계산과 독립 비교 기록에 사용한다. 자동 운전자의 경사 보상은 항법 추정값을 사용하고 마지막 평지 주차 제어는 속도 피드백과 구름저항만 사용한다. 합성 센서·외부 입력 검증·브리지·설정에서 기울기 측정 필드를 제거했다. 실제 경사와 추정 경사는 서로 다른 데이터이며 차량 기울기 그림은 추정값에만 연결한다.

## 자동 주차 정렬 (v2.9)

입차 시나리오의 마지막 18m에서 저속 주차 제어로 전환한다. 목표 자세는 B2 주차면 중심 (58.875, 95.5), 방향 -π/2이다. 경로 점 사이에 투영한 최근접 위치에서 접선 방향과 곡률을 보간하며, 곡률에 방향·횡방향 오차 피드백을 더해 조향을 계산한다. 일반 주차 접근 목표 속도는 1.2m/s, 회전·최종 진입은 0.65m/s 이하이다.

마지막 직선에서는 주차면 중심선과 목표 방향을 직접 추종한다. 목표까지 0.35m 이내인데 정렬 기준을 만족하지 못하면 브레이크로 감속한 뒤 후진하고, 목표점에서 3.5m 떨어진 지점까지 공간을 확보해 다시 전진 정렬한다. 후진 때는 방향 피드백 부호를 반대로 적용한다. 기어 방향을 바꾸기 전에 속도 절댓값을 0.025m/s 이하로 낮춘다. 후진 목표 속도는 최대 0.55m/s이다.

P 전환 조건은 중심선 오차 0.08m 이하, 목표 방향 차이 1° 이하, 종방향 위치가 목표점 앞 0.2m~뒤 0.05m, 속도 절댓값 0.08m/s 미만이다. 이후 기존의 P + 2초 정차 조건으로 주차를 기록한다. 이 값은 제어 기준이며 측정한 성능 보장이 아니다. 차량이 움직이지 않은 상태에서 좌표나 heading을 맞추지 않으며 물리 충돌·센서 생성·센서 전용 추정은 그대로 적용한다. 외부 파일·스트림은 자동 운전자가 개입하지 않는다. 사용자 요청에 따라 실행 테스트는 수행하지 않는다.
